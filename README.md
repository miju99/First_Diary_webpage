# First_Diary_webpage
- 일정을 정리할 수 있는 다이어리

## 제작 목적
- HTML을 활용한 웹 페이지 구조 설계 및 구현
- 사용자 편의성에 맞춘 다이어리 제작

## 주요 기능
- **월 별 일정 관리** : 월 별 일정을 한눈에 파악하고 확인할 수 있습니다.
- **원형 시간표 (Time Visualizer)** : 하루의 계획을 시각적인 원형 시간표 형태로 확인할 수 있습니다.
- **투두 리스트 (To-Do List)** : 일정에 넣기 힘든 여러 할 일들을 체크리스트로 정리할 수 있습니다.
- **소요 시간 계산** : 일정별 소요 시간을 자동으로 계산해 줍니다.
- **아이젠하워 스타일 매트릭스** : 중요한 일과 급한 일을 분류하여 오늘의 일정을 효율적으로 우선순위화합니다.
- **데이터 저장 및 불러오기** : 작성한 데이터를 json 파일로 저장하고 다시 불러올 수 있습니다.
